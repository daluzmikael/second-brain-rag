# 2D Random Walk Simulation

A simple Python script that simulates and visualizes a **2D random walk**.  
The program models step-by-step movement on an X–Y plane and is useful for
understanding randomness, diffusion, and basic stochastic processes.

---

## Overview

The script generates a random walk by repeatedly choosing a direction
(up, down, left, or right) and updating the current position accordingly.
The resulting path can be analyzed numerically or visualized to observe
emergent behavior over time.

Common uses:
- Intro probability & statistics demos
- Random process simulations
- Visualization practice with Python
- Foundations for more complex motion models

---

## Requirements

- Python 3.x  
- (Optional) `matplotlib` for visualization

Install dependencies if needed:
```bash
pip install matplotlib
```

---

## Running Project
Directly from project directory 
```bash
python 2dwalk.py
```
